# Coliseum

## Descripción

Coliseum es una aplicación desarrollada en Java como proyecto académico.

## Funcionalidades

- Gestión de usuarios.
- Inicio de sesión.
- Calendario.
- Cronómetro.
- Conexión con base de datos.


## Tecnologías utilizadas

- Java
- Visual Studio Code
- Git
- GitHub

## Documentación

La documentación del proyecto se encuentra en la carpeta `docs`, donde se incluyen:

- Requisitos funcionales y no funcionales.
- Stack tecnológico.
- Diagrama UML.
- Casos de uso.
- Diagrama de infraestructura.
