 Stack Tecnológico

- **Lenguaje de Programación**
  - Java (JDK 8+)
  - Lenguaje principal de desarrollo orientado a objetos

- **Interfaz Gráfica (GUI)**
  - Java Swing & AWT
  - Implementación de vistas (`JDialog`, `JPanel`, `JButton`, `CardLayout`, `GridBagLayout`, `BoxLayout`)

- **Base de Datos**
  - MySQL 8.0+
  - Motor de base de datos relacional para la persistencia

- **Conector JDBC**
  - MySQL Connector/J (`com.mysql.cj.jdbc.Driver`)
  - Controlador oficial para la comunicación Java-MySQL

- **Seguridad / Cryptography**
  - `java.security.MessageDigest`
  - Generación de hashes SHA-256 para contraseñas

- **Manejo de Fechas**
  - Java 8 Date & Time API (`LocalDate`, `DayOfWeek`, `YearMonth`)
  - Gestión estructurada de fechas y rutinas del calendario
